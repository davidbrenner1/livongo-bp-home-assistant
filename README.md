# Livongo BP Home Assistant App

A Home Assistant app that imports Livongo blood-pressure readings through the member portal JSON API and publishes the latest values plus `livongo_bp_reading` events to Home Assistant.

This repository is configured to publish a **prebuilt multi-architecture image** to GitHub Container Registry (GHCR). Home Assistant then pulls that image instead of building Chromium locally.

## One-time repository setup

Run this before pushing the repository to GitHub:

```bash
python3 tools/configure_for_github.py davidbrenner1
```

That updates the Home Assistant app image to:

```text
ghcr.io/davidbrenner1/livongo-bp-collector
```

Create a GitHub repository named `livongo-bp-home-assistant`, push this folder to its `main` branch, and GitHub Actions will build and publish `amd64` and `arm64` images.

## Install in Home Assistant

After the GitHub Actions build succeeds and the GHCR package is public:

1. Home Assistant -> Settings -> Apps -> App store.
2. Add this GitHub repository URL as an app repository.
3. Reload the app store.
4. Install **Livongo BP Collector**.
5. Start it and enable Start on boot.
6. Open the Web UI and upload the `livongo-session-bundle.json` generated by the included Mac helper.

## Security

The Livongo browser-session bundle grants access to your Livongo account. Keep it private. The add-on stores it only in its persistent `/data` directory.
